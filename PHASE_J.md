# Phase J — UI Dashboard

Consola operativa servida en el edge: `/ui`

## Tabs
- Overview (foundry / receipts / metrics)
- Search
- Cases
- Metrics + bench
- Foundry types / object view
- Truth receipts

## Uso
1. Deploy branch `phase-j-ui-dashboard`
2. Abrir `https://<worker>/ui`
3. Pegar Bearer token + tenant
4. Refresh / Search / Bench

La página es pública; las APIs siguen autenticadas.
